# 验收记录

日期：2026-11-04（Asia/Shanghai）。

## 构建产物

- 应用：静听·背景音 1.0.0，包名 `com.quiet.background`。
- 支持 Android 8.0+，compile/target SDK 36。
- Release 构建，R8 优化与资源压缩，自有 RSA 3072 位签名，APK v2 签名校验通过。
- SHA-256 见 `../dist/SHA256SUMS.txt`，签名证书信息见 `../dist/signature-verification.txt`。
- 音频全量内置：15 类、83 文件，总时长 14,053 秒。重复雨声压缩包经过哈希比较后去重。
- 83 个源音频均通过 FFmpeg 完整解码。最终 APK 内所有音频 SHA-256 与源文件一致。
